# ferramenta_IR

Ferramenta para auxiliar no controle de dados e valores para declaração de Imposto de Renda. A ferramenta conta com menu navegável feito com o recurso 'link' do Excel, que leva as telas para ser feito o preenchimento. Em cada uma delas tem o título da etapa, uma breve descrição e os campos de preenchimento. O visual da ferramenta é coeso e simples para melhor utilização do usuário.
